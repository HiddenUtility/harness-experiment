# Harness-Driven Development (HDD) System

This repository implements a self-evolving loop for AI agents to continuously improve their own working skills.

## 1. The Self-Evolution Loop

The system operates on a continuous cycle:

1.  **`bugfix`**: Executes standardized bug fixing.
2.  **Quality Guard**: Automatically verifies the fix using `pytest` and `ruff`.
3.  **`retro`**: Conducts a KPT (Keep, Problem, Try) retrospective.
4.  **`improve-skill`**: Creates concrete improvements based on 'Try' items.
5.  **`eval-skill`**: Validates the improved skill against evaluation criteria.
6.  **Adoption**: If the evaluation passes, a Pull Request is created for human review.

## 2. Skill Definitions

Skills are defined in `.agent/skills/`. Each skill follows a strict workflow to ensure consistency and quality.

- [bugfix](.agent/skills/bugfix/SKILL.md): Standardizes bug fixing.
- [eval-skill](.agent/skills/eval-skill/SKILL.md): Validates skill improvements.
- [retro](.agent/skills/retro/SKILL.md): Performs KPT retrospectives.
- [improve-skill](.agent/skills/improve-skill/SKILL.md): Proposes and tests skill improvements.

## 3. Quality Guard

The quality guard is implemented in `scripts/quality_guard.py`. It ensures:
- All code complies with `ruff` linting rules.
- All tests pass via `pytest`.

Any failure in the quality guard stops the automated flow.

## 4. Documentation & Reports

- **Retrospectives**: All KPT logs are stored in `docs/retrospectives/`.
- **Evaluation Reports**: All skill evaluation results are stored in `docs/dryrun-reports/`.

## 5. Workflow & Automation

### Automated Flow (to `dev` branch)
An "Auditor Agent" or the orchestration logic can automatically merge changes to the `dev` branch once:
- The bugfix is verified by the Quality Guard.
- The skill improvement is verified by `eval-skill`.

### Human-in-the-loop (to `main` branch)
- All merges to `main` are manual.
- Humans review the Pull Requests generated by `improve-skill`, checking the attached evaluation reports.

## 6. How to Use

To fix a bug, simply invoke the `bugfix` skill. The skill will guide you through the process, including the mandatory retrospective at the end.
