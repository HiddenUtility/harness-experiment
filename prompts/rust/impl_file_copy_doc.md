# 全体
- Rust使用
- Tokio使用
- クレートのsrc階層にはREADME.mdを用意して，簡単なドキュメントとサンプルコードを準備する．
- docstringに仕様書いて，コメントアウトによる説明は極力書かないようにする．
- lib.rs に全部書かずに適切にファイル分割すること

## ファイルをコピーするオブジェクト
- 引数は
    - ターゲットの file_path: PathBuf
    - 出力先のディレクトリパス dir_path: PathBuf
- 出力先なければ作成する
- 同名のファイルが出力先にあったら削除する
- 途中は 拡張子のあとに .temp のサフィックスをつけ，成功していれば 正式な拡張子に戻す．
- すでに同名 .temp のがあったら削除する
- 途中で 失敗したら， .temp は極力削除する．
- 標準の std::io::Result 使用して，メッセージ内容でエラー判別する
- リネイムまですべて成功したら元ファイルを消すバージョンと消さないバージョン関数を用意する．


## ディレクトリをコピーするオブジェクト
- 引数は
    - ターゲットのディレクトリパス dir_path: PathBuf
    - 出力先のファイパス dest_path: PathBuf
- 出力先のディレクトリなければ作成する
- 同名の出力先があったら削除する
- コピー途中はディレクトリ名に _temp サフィックスを追加して，成功していれば サフィックを消して正式なものに戻す．
- すでに同名 _temp のがあったら削除する
- 圧縮途中で 失敗したら， _temp は極力削除する．
- 標準の std::io::Result 使用して，メッセージ内容でエラー判別する
- リネイムまですべて成功したら成功したら元ディレクトリを消すバージョンと消さないバージョンの2パターンの関数を用意する．


## 詳細設定ができるディレクトリをコピーする関数するオブジェクト
- あとで変更しやすいようにオプションは別構造体で定義しておく．
- コンストラクタ new の引数は
    - ターゲットのディレクトリパス dir_path: PathBuf
    - 出力先のファイパス dest_path: PathBuf 
- 最初からオプションを設定できる new_with も用意する
- メソッドチェーンでオプションを変更可能にする
    - ターゲットディレクトリ内で出力先に含めないファイル名正規表現パターンを追加する関数
    - ターゲットディレクトリ内で出力先に含めないフォルダ名正規表現パターンを追加する関数
- 出力先のディレクトリなければ作成する
- 同名の出力先があったら削除する
- コピー途中はディレクトリ名に _temp サフィックスを追加して，成功していれば サフィックを消して正式なものに戻す．
- すでに同名 _temp のがあったら削除する
- 圧縮途中で 失敗したら， _temp は極力削除する．
- 標準の std::io::Result 使用して，メッセージ内容でエラー判別する
- リネイムまですべて成功したら元ディレクトリを消すバージョンと消さないバージョンの2パターンの関数を用意する．
- 出力先に含めないファイル名パターン,フォルダ名正規表現パターンに合致していた場合は出力先に含めない
