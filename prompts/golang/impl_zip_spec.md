# ZIP圧縮ライブラリ 実装仕様書（Go版）

## 1. 概要

Goを使用して、ファイルおよびディレクトリをZIP形式で圧縮するライブラリを実装する。

以下の3種類のZIP圧縮機能を提供する。

1. 単一ファイルをZIP圧縮する機能
2. ディレクトリをZIP圧縮する機能
3. 除外パターンなどの詳細設定が可能なディレクトリZIP圧縮機能

また、すべての機能について、同期版と非同期版を提供する。

実装はGoの標準ライブラリを優先し、不要な外部依存を追加しない。

## 2. 全体的な実装方針

### 2.1 使用言語・ライブラリ

- Goを使用する。
- ZIP形式の作成には `archive/zip` を使用する。
- ファイル・ディレクトリ操作には標準ライブラリの `os` および `path/filepath` を使用する。
- 正規表現には標準ライブラリの `regexp` を使用する。
- 非同期処理には goroutine と channel を使用する。
- 不必要な外部依存ライブラリを追加しない。

### 2.2 ディレクトリ構成

以下の場所に実装する。

```text
pjt/
└── pkg/
    └── pkg-name/
            ├── README.md
            ├── file_zip.go
            ├── dir_zip.go
            ├── dir_zip_options.go
            ├── async.go
            ├── errors.go
            └── ...
```

実際のファイル分割は責務に応じて適切に変更してよい。

ただし、以下を必須とする。

- `lib.rs` に相当する1ファイルにすべての処理を記述するような構成にしない。
- 処理の責務ごとにファイルを分割する。
- `src/README.md` を用意する。
- README.mdにはライブラリの概要、各機能の説明、使用方法、サンプルコードを記載する。
- 公開APIにはGoのdoc commentを記述する。
- コメントによる冗長な説明は避け、必要な仕様や制約をdoc commentに記載する。

### 2.3 エラー処理

- エラーにはGo標準の `error` 型を使用する。
- エラーを無視しない。
- エラー発生時には、原因を追跡できるように `fmt.Errorf` と `%w` を使用して適切にラップする。
- ファイル操作、ZIP操作、リネーム、削除などのエラーを呼び出し元に返す。
- エラーの種類を判定できるように、必要に応じて独自のエラー変数を定義する。
- エラーを返す関数では、原則として最後の戻り値を `error` とする。

### 2.4 同期処理・非同期処理

すべての機能について同期版と非同期版を実装する。

**同期版**

通常のGo関数として実装する。

**非同期版**

goroutineを利用して同期版の処理を実行する。

非同期版から同期版の処理を再利用し、圧縮処理の実装を重複させない。

非同期版は、処理結果をchannel経由で呼び出し元に通知する。

Goには標準的なasync/await構文が存在しないため、Goの一般的なgoroutine/channelによる非同期APIとして実装する。

同期版・非同期版で処理結果およびエラー仕様を統一する。

## 3. 共通仕様

### 3.1 ZIP圧縮レベル

ZIP圧縮レベルは以下の範囲とする。

- デフォルト値：6
- 最小値：0
- 最大値：9

範囲外の値が指定された場合はエラーを返す。

Goの `archive/zip` では以下を使用する。

- `zip.Store`：圧縮なし（レベル0相当）
- `zip.Deflate`：Deflate圧縮（レベル1～9）

Deflateの圧縮レベル指定には `compress/flate` の `flate.NewWriter` を使用する。

圧縮レベル0の場合は `zip.Store` を使用する。

圧縮レベル1～9の場合は `zip.Deflate` と指定レベルのDeflate Writerを使用する。

圧縮レベルの指定を正しくZIPエントリに反映すること。

### 3.2 一時ファイル

ZIP圧縮中は、一時ファイルに書き込む。

正式な出力ファイルと一時ファイルの関係は以下とする。

```text
正式な出力ファイル：sample.zip
一時ファイル      ：sample.zip.temp
```

一時ファイル名は正式な出力ファイル名に `.temp` を追加したものとする。

ディレクトリ圧縮で出力先が `backup.dat` の場合は以下とする。

```text
正式な出力ファイル：backup.dat
一時ファイル      ：backup.dat.temp
```

圧縮開始時に同名の一時ファイルが存在する場合は削除する。

一時ファイルの削除に失敗した場合はエラーを返す。

圧縮処理中にエラーが発生した場合は、一時ファイルを可能な限り削除する。

一時ファイルの削除に失敗した場合は、元の圧縮エラーを優先し、削除エラーも追跡可能な形で扱うこと。

### 3.3 既存の出力先ファイル

既存の出力先ファイルが存在する場合でも、新しいZIPファイルの作成と一時ファイルから正式ファイルへのリネームが成功するまでは既存ファイルを残す。

処理手順は以下とする。

1. 一時ファイルを作成する。
2. ZIPデータを書き込む。
3. ZIP Writerを正常終了する。
4. 一時ファイルを正常にクローズする。
5. 一時ファイルを正式な出力ファイルにリネームする。
6. すべて成功した場合に限り、元データを削除する（削除するバージョンの場合）。

既存の出力先ファイルを圧縮開始前に削除してはならない。

一時ファイルから正式な出力ファイルへのリネームには `os.Rename` を使用する。

既存ファイルを残したまま置き換える必要があるため、OSごとの `os.Rename` の挙動を確認すること。

特にWindowsでは既存ファイルへのリネームが失敗する場合がある。

既存ファイルの保護を優先し、置き換えに失敗した場合は既存ファイルを削除して無理にリネームしないこと。

その場合はエラーを返し、一時ファイルの後始末を行う。

### 3.4 ディレクトリ作成

出力先ディレクトリまたは出力先ファイルの親ディレクトリが存在しない場合は、`os.MkdirAll` を使用して作成する。

ディレクトリ作成に失敗した場合はエラーを返す。

### 3.5 シンボリックリンク

圧縮対象にシンボリックリンクが存在する場合は無視する。

- シンボリックリンク自体をZIPに含めない。
- シンボリックリンクの参照先も圧縮しない。
- ディレクトリへのシンボリックリンクを再帰探索しない。

`os.Lstat` を使用してシンボリックリンクを判定する。

### 3.6 元データの削除

元データを削除する機能を持つ場合、削除処理は以下の順序で実行する。

1. ZIPファイルの作成を開始する。
2. ZIPの書き込みを完了する。
3. ZIP Writerを正常終了する。
4. ファイルをクローズする。
5. 一時ファイルを正式な出力ファイルにリネームする。
6. ここまでのすべてが成功した場合のみ元データを削除する。

削除に失敗した場合はエラーを返す。

ディレクトリの削除では `os.RemoveAll` を使用する。

ファイルの削除では `os.Remove` を使用する。

削除途中でエラーが発生した場合、一部の元データだけが削除された状態になる可能性は許容する。

ただし、ZIPファイルの作成またはリネームが失敗した場合は、元データを絶対に削除してはならない。

## 4. 単一ファイルのZIP圧縮

### 4.1 概要

単一ファイルをZIP形式で圧縮する機能を実装する。

圧縮レベルは6とする。

### 4.2 引数

```go
filePath string
dirPath  string
```

- `filePath`：圧縮対象のファイルパス
- `dirPath`：ZIPファイルの出力先ディレクトリ

### 4.3 出力ファイル名

元ファイルの拡張子を `.zip` に変更する。

例：

```text
入力：
/data/sample.txt

出力：
/backup/sample.zip
```

元ファイル名のベース部分は維持する。

拡張子を持たないファイルの場合も、末尾に `.zip` を追加する。

例：

```text
sample → sample.zip
```

出力先ディレクトリが存在しない場合は作成する。

### 4.4 ZIP内部の構造

ZIP内部には対象ファイルを1つだけ格納する。

ZIP内部のファイル名は元ファイル名とする。

例：

```text
sample.zip
└── sample.txt
```

絶対パスや出力先ディレクトリのパスをZIP内部に含めない。

### 4.5 提供する関数

以下の2種類の関数を提供する。

**元ファイルを削除しない関数**

```go
func CompressFile(filePath, dirPath string) error
```

**元ファイルを削除する関数**

```go
func CompressFileAndRemove(filePath, dirPath string) error
```

元ファイルを削除する関数は、ZIPの作成と正式な出力ファイルへのリネームがすべて成功した場合にのみ元ファイルを削除する。

削除に失敗した場合はエラーを返す。

### 4.6 非同期関数

同期版に対応する非同期関数を提供する。

例：

```go
func CompressFileAsync(filePath, dirPath string) <-chan error

func CompressFileAndRemoveAsync(filePath, dirPath string) <-chan error
```

非同期関数はgoroutine内で対応する同期関数を実行し、結果をchannelに送信する。

処理終了後はchannelを必ずcloseする。

## 5. ディレクトリのZIP圧縮

### 5.1 概要

指定したディレクトリを再帰的にZIP圧縮する。

圧縮レベルは6とする。

### 5.2 引数

```go
dirPath string
zipPath string
```

- `dirPath`：圧縮対象のディレクトリパス
- `zipPath`：ZIPファイルの出力先パス

`zipPath` は `.zip` 以外の拡張子でも使用できる。

### 5.3 ZIP内部のディレクトリ構造

対象ディレクトリ自体をZIP内部に含める。

例：

対象ディレクトリ：

```text
/data/target/
├── file1.txt
├── file2.txt
└── sub/
    └── file3.txt
```

ZIP内部：

```text
target/
├── file1.txt
├── file2.txt
└── sub/
    └── file3.txt
```

ZIP内部のルートディレクトリ名は対象ディレクトリのベース名とする。

絶対パスはZIP内部に含めない。

サブディレクトリは再帰的に圧縮する。

空のディレクトリもZIP内部に保持する。

### 5.4 出力先

出力先の親ディレクトリが存在しない場合は作成する。

同名の出力先ファイルが存在する場合でも、新しいZIPファイルが正常に完成するまでは既存ファイルを残す。

### 5.5 提供する関数

**元ディレクトリを削除しない関数**

```go
func CompressDir(dirPath, zipPath string) error
```

**元ディレクトリを削除する関数**

```go
func CompressDirAndRemove(dirPath, zipPath string) error
```

削除する関数は、ZIP作成と正式ファイルへのリネームが成功した場合のみ元ディレクトリを削除する。

削除には `os.RemoveAll` を使用する。

### 5.6 非同期関数

```go
func CompressDirAsync(dirPath, zipPath string) <-chan error

func CompressDirAndRemoveAsync(dirPath, zipPath string) <-chan error
```

同期版をgoroutineから実行する。

## 6. 詳細設定可能なディレクトリZIP圧縮

### 6.1 概要

圧縮レベルや除外パターンを設定できるディレクトリZIP圧縮機能を実装する。

オプションは独立した構造体で管理する。

### 6.2 オプション構造体

以下のような構造体を用意する。

```go
type DirZipOptions struct {
    CompressionLevel int
    ExcludeFiles      []*regexp.Regexp
    ExcludeDirs       []*regexp.Regexp
}
```

必要に応じて内部実装を追加してよい。

デフォルト値は以下とする。

```go
DirZipOptions{
    CompressionLevel: 6,
    ExcludeFiles:     nil,
    ExcludeDirs:      nil,
}
```

オプションの初期化時に圧縮レベルが0～9の範囲内であることを検証する。

範囲外の場合はエラーとする。

### 6.3 コンストラクタ

以下の2種類を提供する。

**デフォルトオプションで初期化する**

```go
func NewDirZip(dirPath, zipPath string) *DirZip
```

**オプションを指定して初期化する**

```go
func NewDirZipWith(
    dirPath, zipPath string,
    options DirZipOptions,
) (*DirZip, error)
```

`NewDirZip` はデフォルトのオプションを使用する。

`NewDirZipWith` は渡されたオプションを検証してから初期化する。

### 6.4 メソッドチェーン

メソッドチェーンによってオプションを変更できるようにする。

以下のメソッドを提供する。

**圧縮レベルの変更**

```go
func (z *DirZip) SetCompressionLevel(level int) *DirZip
```

- 圧縮レベルは0～9とする。
- 範囲外の値はエラーとして扱う。
- エラーを保持する内部フィールドを設け、最終的な圧縮処理時にエラーを返すなど、メソッドチェーンを維持できる設計とする。

**ファイル名の除外パターン追加**

```go
func (z *DirZip) AddExcludeFilePattern(pattern string) *DirZip
```

- 正規表現をコンパイルする。
- コンパイルに失敗した場合はエラーとして保持する。
- 複数登録できる。

**ディレクトリ名の除外パターン追加**

```go
func (z *DirZip) AddExcludeDirPattern(pattern string) *DirZip
```

- 正規表現をコンパイルする。
- コンパイルに失敗した場合はエラーとして保持する。
- 複数登録できる。

各メソッドは `*DirZip` を返す。

### 6.5 圧縮処理メソッド

以下の2種類を提供する。

**元ディレクトリを削除しない**

```go
func (z *DirZip) Compress() error
```

**元ディレクトリを削除する**

```go
func (z *DirZip) CompressAndRemove() error
```

### 6.6 非同期処理メソッド

```go
func (z *DirZip) CompressAsync() <-chan error

func (z *DirZip) CompressAndRemoveAsync() <-chan error
```

goroutine内で同期版のメソッドを実行する。

## 7. 除外パターンの仕様

### 7.1 ファイル名の除外

ファイル名の正規表現は、ファイルのベース名だけを対象とする。

ディレクトリパスを含めて判定してはならない。

例：

```text
対象：
/data/target/sub/sample.log

判定対象：
sample.log
```

以下のパターンを指定した場合、

```regex
\.log$
```

すべての階層に存在する `.log` ファイルを除外する。

### 7.2 ディレクトリ名の除外

ディレクトリ名の正規表現は、ディレクトリのベース名だけを対象とする。

例：

```text
対象：
/data/target/sub/temp/

判定対象：
temp
```

### 7.3 除外判定

- ファイル名パターンは複数登録できる。
- ディレクトリ名パターンは複数登録できる。
- いずれか1つでも一致した場合は除外する。
- 正規表現の判定には `regexp.Regexp.MatchString` を使用する。

### 7.4 ディレクトリ除外時の動作

ディレクトリが除外された場合、そのディレクトリ自体と配下のすべてのファイル・ディレクトリを除外する。

除外されたディレクトリの内部を探索してはならない。

`filepath.WalkDir` を使用する場合は、除外対象ディレクトリに対して `filepath.SkipDir` を返す。

### 7.5 シンボリックリンク

詳細設定版でもシンボリックリンクは無視する。

シンボリックリンクの参照先を探索してはならない。

## 8. 非同期APIの共通仕様

### 8.1 実装方式

Goのgoroutineを使用して非同期処理を実装する。

非同期版から対応する同期版を呼び出す。

圧縮処理のロジックを非同期版に重複実装してはならない。

### 8.2 channelによる結果通知

非同期関数は `<-chan error` を返す。

実装例：

```go
func CompressFileAsync(
    filePath, dirPath string,
) <-chan error {
    result := make(chan error, 1)

    go func() {
        defer close(result)
        result <- CompressFile(filePath, dirPath)
    }()

    return result
}
```

上記は実装例であり、他の非同期関数も同じ設計方針で実装する。

channelはバッファサイズ1とする。

処理結果を必ず1回通知し、その後channelをcloseする。

### 8.3 同期版との整合性

- 同期版と非同期版で同じ圧縮結果を生成する。
- 同期版と非同期版で同じエラー条件とエラー内容を維持する。
- 非同期版では同期版の処理を再利用する。
- goroutine内で発生したエラーはchannel経由で通知する。

## 9. 入力値の検証

圧縮開始前に以下を検証する。

### 9.1 ファイル圧縮

- 入力ファイルが存在すること。
- 入力パスが通常ファイルであること。
- ディレクトリやシンボリックリンクを入力ファイルとして受け付けないこと。
- 出力先ディレクトリを作成できること。

### 9.2 ディレクトリ圧縮

- 入力ディレクトリが存在すること。
- 入力パスがディレクトリであること。
- シンボリックリンクを入力ディレクトリとして受け付けないこと。
- 出力先の親ディレクトリを作成できること。

### 9.3 出力先の検証

出力先が入力元と衝突しないことを検証する。

特に、出力ZIPファイルや一時ファイルが圧縮対象ディレクトリ内部に作成される場合、ZIP自身が圧縮対象に含まれないようにすること。

削除する関数では、圧縮対象と出力先が同一または重複することで元データを誤削除することがないように検証する。

検証できない、または安全性を保証できない場合はエラーを返す。

## 10. テスト仕様

単体テストを作成する。

テストにはGo標準の `testing` パッケージを使用する。

### 10.1 ファイル圧縮

以下をテストする。

- 正常にZIP圧縮できる。
- ZIP内部のファイル名が元ファイル名になっている。
- 圧縮レベル6で圧縮できる。
- 出力先ディレクトリが存在しない場合に自動作成される。
- 既存のZIPファイルが正常終了まで保持される。

- 圧縮失敗時に一時ファイルが可能な限り削除される。

- 元ファイルを削除する関数では正常終了後に元ファイルが削除される。

- ファイル名とディレクトリ構造が維持される。

- 既存の出力ファイルが保持される。
- 一時ファイルの後始末が正しく行われる。
- 元ディレクトリを削除しない関数では元データが残る。

### 10.3 詳細設定版

以下をテストする。

- 圧縮レベル0が使用できる。

以下をテストする。

- ファイルへのシンボリックリンクが無視される。
- ディレクトリへのシンボリックリンクが無視される。
- シンボリックリンクの参照先が圧縮されない。

シンボリックリンクのテストは、実行環境で作成できない場合には適切にスキップする。

### 10.5 非同期処理

以下をテストする。

- 非同期版が正常終了する。
- 非同期版のエラーがchannel経由で返る。
- 処理終了後にchannelがcloseされる。
- 同期版と非同期版で同じ結果になる。
- 非同期処理が呼び出し元のgoroutineをブロックしない。

## 11. 実装上の注意事項

1. ZIP Writerの `Close()` を必ず呼び出すこと。
2. ZIP WriterのCloseで発生したエラーを無視しないこと。
3. 出力ファイルのCloseで発生したエラーを無視しないこと。
4. ZIPファイルを正式な出力先にリネームする前に、すべての書き込みとCloseが成功していることを確認すること。
5. 元データの削除は正式な出力ファイルへのリネーム後に限定すること。
6. 既存の出力ファイルを圧縮開始前に削除しないこと。
7. 圧縮対象のパスをZIP内部に絶対パスとして記録しないこと。
8. パストラバーサルにつながるZIPエントリ名を生成しないこと。
9. ZIP内部のパス区切り文字には `/` を使用すること。
10. ファイルの読み込み・書き込みに失敗した場合は適切にエラーを返すこと。
11. ファイルやディレクトリの権限エラーを無視しないこと。
12. 一時ファイルの後始末を可能な限り実施すること。
13. 同じ `DirZip` インスタンスを複数のgoroutineから同時に操作することは想定しない。必要以上に複雑な排他制御を追加しないこと。
