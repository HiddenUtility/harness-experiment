Rust使用
reqwest使用

簡易的な 非同期の http client (handler) を作成．
GET, POST, PUT, DELETE を別々の関数で実装．
json使うAPIを想定

Client インスタンスに設定を保持する方式
Authorizationヘッダーに認証トークンを任意追加できるように設計．
Authorization 以外の任意の HTTP ヘッダーも追加可能にする．
レスポンスボディは ジェネリック型を使用 して任意の構造体に変換
Result<T, HttpClientError> で統一する
HttpClientErrorに各エラーが区別できるように設計する，関数を実装する
    - HTTP ステータスコードが 2xx 以外ならエラー
        - 401 など 再認証を促す必要あるやつは特定できる関数あると助かる
    - 通信エラーも区別する
    - JSON の変換エラーも区別する
    - タイムアウトはエラーも区別する
クエリパラメータ：GET フルのurl を渡す．クエリパラメータ付きの url作成する関数を別に用意してあげるか， get用構造体用の GETを実装して，get用構造体事態にパラメータを追加する関数を実装する．
タイムアウト：設定可能にする（デフォルト30秒）
リトライ：実装しない
すべての HTTP メソッドで、完全な URL を渡す設計
