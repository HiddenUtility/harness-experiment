# eval-skill

## 入力

- 評価対象のスキル定義ファイル (e.g., `docs/skills/xxx.md`)
- 改善案の内容 (Diff または 新しい定義)
- 評価用タスクの定義

## 手順

1. 評価対象のスキルと、改善前のバージョンを比較する
2. 指定された評価用タスクに改善後のスキルを適用する
3. 以下の3つの軸で評価を実施する
    - **再現性**: 別の類似タスクでも同じ手順で安定して動作するか
    - **改善度**: 以前のバージョンで発生した問題が解消されているか
    - **副作用**: 新しい問題や予期しない挙動を発生させていないか
4. 評価結果を `docs/dryrun-reports/` 内にレポートとして出力する
5. 判定基準:
    - すべての軸が PASS であれば、総合評価を PASS とする
    - 一つでも FAIL があれば、総合評価を FAIL とする
6. 評価結果を改善案の作成プロセスに返す

## 出力

- 評価レポート (`docs/dryrun-reports/eval_report_$(date +%Y%m%d_%H%M%S).md`)
