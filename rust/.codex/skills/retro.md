# retro

## 入力

- 実行したスキルの種類
- 実行ログ
- テスト結果 / 品質ガード結果
- (取得可能であれば) トークン消費量 / 概算費用

## 手順

1. 実行ログ、テスト結果、品質ガード結果、評価レポートを参照する
2. 以下の KPT テンプレートを用いて振り返りを作成する
    - **Keep**: うまくいったこと、継続すべきこと
    - **Problem**: 問題点、失敗したこと、非効率だったこと
    - **Try**: 次回に向けた具体的な改善案
3. **Try** には必ず以下の詳細を含める
    - 改善対象のスキル名
    - 発生した問題と原因
    - 改善内容
    - 期待する効果
4. 数値を記録する:
    - 実装時間
    - テスト実行結果
    - 品質ガード結果
    - トークン消費量
    - 概算費用
5. 作成した KPT を `docs/retrospectives/` に保存する
6. 完了時に `improve-skill` スキルを呼び出す

## 出力

- KPT ファイル (`docs/retrospectives/retro_$(date +%Y%m%d_%H%M%S).md`)
